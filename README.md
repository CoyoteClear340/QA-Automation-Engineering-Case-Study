# QA Automation Case Study – B2B SaaS Platform (WorkflowPro)

This repository contains my solution for a QA Automation case study.  
It demonstrates how to test a multi-tenant B2B SaaS platform using:

- Pytest (test runner)
- Playwright (Web UI automation)
- Python Requests (API testing)
- Selenium + BrowserStack (mobile web validation)

The goal of the assignment was to design tests that validate quality across API, UI, mobile, and tenant security layers.
